## What to build

最小的一条完整路径：在任何 App 里按 ⌥C，绳子从屏幕顶部落下并拿到键盘，←→ 挑一件，⏎ 把它贴回刚才打字的地方。全局只剩 ⌥C 一个键。这一步不改绳子的样子，也不加篮子，只验证最没把握的三件事：全局快捷键、拿键盘却不抢前台、对前台 App 发粘贴。依据 [T-002](T-002-only-option-c-global.md)、[T-008](T-008-summon-position.md)。

## Acceptance

- [ ] 全局只注册 ⌥C；⌃⌥T、⌃⌥F 和指针停在绳上时临时注册的全局键都不存在了。自动检查确认注册表里只有 ⌥C。
- [ ] 按 ⌥C：绳子落在指针所在屏幕的顶部，面板拿到键盘，前台 App 不变（菜单栏左上角还是那个 App 的名字）。
- [ ] 打开时最新的一件被选中，选中那件有明显标记；←→ 移动选中。
- [ ] ⏎：绳子收起，选中那件贴进刚才那个 App 的光标处；之后手动 ⌘V 贴出的也是它。
- [ ] 没给辅助功能权限时，⏎ 只复制，提示「已复制，按 ⌘V 粘贴」，并给出去授权的入口；授权后不用重开 EnCopy 就能直接贴。
- [ ] Esc 或再按一次 ⌥C 收起；收起后方向键、⏎、⌘Z 在前台 App 里照常工作。
- [ ] 自动检查：移动选中、⏎ 放上剪贴板的内容、发出的粘贴请求都正确，且全部用私有剪贴板，不碰系统剪贴板。
- [ ] 真机：在备忘录、微信、终端里各走一遍「⌥C → → → ⏎」，焦点不跑、贴进去的是选中那件。留录屏或截图和步骤。
