## What to build

最小的一条完整路径：在任何 App 里按 ⌥C，绳子从屏幕顶部落下并拿到键盘，←→ 挑一件，⏎ 把它贴回刚才打字的地方。全局只剩 ⌥C 一个键。这一步不改绳子的样子，也不加篮子，只验证最没把握的三件事：全局快捷键、拿键盘却不抢前台、对前台 App 发粘贴。依据 [T-002](T-002-only-option-c-global.md)、[T-008](T-008-summon-position.md)。

## Acceptance

- [x] 全局只注册 ⌥C；⌃⌥T、⌃⌥F 和指针停在绳上时临时注册的全局键都不存在了。自动检查确认注册表里只有 ⌥C。
- [x] 按 ⌥C：绳子落在指针所在屏幕的顶部，面板拿到键盘，前台 App 不变（菜单栏左上角还是那个 App 的名字）。
- [x] 打开时最新的一件被选中，选中那件有明显标记；←→ 移动选中。
- [x] ⏎：绳子收起，选中那件贴进刚才那个 App 的光标处；之后手动 ⌘V 贴出的也是它。
- [x] 没给辅助功能权限时，⏎ 只复制，提示「已复制，按 ⌘V 粘贴」，并给出去授权的入口；授权后不用重开 EnCopy 就能直接贴。
- [x] Esc 或再按一次 ⌥C 收起；收起后方向键、⏎、⌘Z 在前台 App 里照常工作。
- [x] 自动检查：移动选中、⏎ 放上剪贴板的内容、发出的粘贴请求都正确，且全部用私有剪贴板，不碰系统剪贴板。
- [x] 真机：在备忘录、微信、终端里各走一遍「⌥C → → → ⏎」，焦点不跑、贴进去的是选中那件。留录屏或截图和步骤。

## Resolution

完成。实现提交 `853f813`，分支 `feat/T-012-summon-and-paste`。证据在本地的 `evidence/T-012/`（不进 git）。有一种情形没做到，转给 [T-015](T-015-summon-moves-to-pointer-screen.md)：绳子已经露在另一块屏上时按 ⌥C，它不会挪到指针所在的屏。

- **全局只有 ⌥C**：默认快捷键改成 ⌥C；源码里注册全局快捷键的地方只剩 `registerShortcut()` 一处。自动检查分两半：`scripts/check.sh` 第 2 步要求 `HotKey(` 只有一处调用、`RegisterEventHotKey` 只出现在 `HotKey.swift`、没有监听按键的全局监视器；本地检查确认默认快捷键是 ⌥C。检查里不真的注册快捷键（那会抢走系统里的 ⌥C），所以它确认的是「只有一处注册，注册的是 ⌥C」，不是运行时的注册表。真机上按 ⌃⌥T、⌃⌥F，绳子不出现。
- **叫它来**：⌥C 走 `summon()`。真机上指针在主屏和第二块屏各按一次，绳子都落在指针所在那块屏的顶部，搜索框拿到键盘，前台 App 没变（`walk-03-summoned-in-notes.png`、`walk-09-second-display.png`）。
- **选中**：新增 `Line.picked`，和鼠标多选的 `selectedIDs` 分开；词汇表加了「选中 / picked」。打开时最新的一件带蓝色描边和对勾，← 移到左边一件，→ 移回来（`walk-04-picked-older.png`）。这一步没改绳子的排法，最新的在最右边，所以往更早的方向是 ←；工单里写的「→」要等第 ④ 步把最新的挪到绳结旁边。
- **搜索和输入法**：打字「1111」后绳上只剩匹配的那件并选中它，⏎ 贴的是它（`walk-07-search-1111.png`）。微信输入法组字时按 ←，选中不动，方向键归输入法（`walk-08-composing.png`）。
- **贴**：新增 `Sources/EnCopy/Paste.swift`。⏎ 先把选中那件放上剪贴板、收起绳子，再对前台 App 发 ⌘V，中间不等。在备忘录里 0.3 秒内贴进光标处，再手动 ⌘V 贴出的是同一段（`walk-11-notes-pasted-crop.png`、`keytap-paste.log`）。
- **没有辅助功能权限**：⏎ 只复制，屏幕顶部出现「已复制，按 ⌘V 粘贴」和「去授权…」（`walk-05-untrusted-hint.png`）。用户用真键盘按 ⌥C 和 ⏎、用鼠标点「去授权…」、在系统设置里打开开关，都有反应；之后同一个进程（没有重开）直接能贴。
- **收起**：Esc 收起，再按一次 ⌥C 也收起。收起后在备忘录里打字、按 ←、按 ⏎、按 ⌘Z 都是备忘录自己的反应。
- **三个 App**：备忘录、终端、微信（文件传输助手的输入框，只贴不发，贴完用 ⌘Z 撤掉）各走了「⌥C、←、⏎」，前台 App 都没变，贴进去的都是选中的那件（`walk-13-terminal-pasted-crop.png`、`walk-16-wechat-pasted.png`）。
- **自动检查**：`scripts/check.sh` 输出 `88 strings, checked in en, zh-Hans` 和 `108 checks passed`，原有 80 项没有改动（`check.log`）。新增 28 项覆盖移动选中、搜索后选中跟着走、取下后选中换成最新的、⏎ 放上私有剪贴板的内容、发出的按键和先收起再发的顺序、没权限时不发、长绳滚动、面板只拿不带修饰键的 ←→。8 个变异都被抓到（`mutants.log`）。
- **检查不再碰真实数据**：`check.sh` 给检查程序一个临时的 home 目录。之前检查程序里的搜索索引和便签文件夹指向用户真实的 `Application Support/EnCopy/`；现在跑完一遍，那个文件夹里没有任何文件被动过（`isolation.log`）。

真机上发现并改掉的一处：⌘V 的按键抬起原来也带 ⌘。系统把最后一个合成事件的标志当成当前按住的修饰键，所以每贴一次，⌘ 就一直算作按着，直到下一次真的按修饰键。实测见 `stickprobe.log`；现在抬起不带修饰键，贴完后查到的修饰键状态是空的，并加了一项检查。

留下的事：

- 授权后的第一次 ⏎，文字没有在 1.6 秒内出现，后来发现它贴进去了，什么时候贴的没看到；之后每次都在 0.3 秒内。只出现过一次，原因没查到，下次授权时用 `evidence/tools/keytap` 量一下（记在 [T-015](T-015-summon-moves-to-pointer-screen.md)）。
- `Line.onUndoableAction` 现在没有调用方，只有原有的一项检查还在用。第 ③ 步做「⌘Z 放回」时一起处理。
- 「去授权…」第一次点会同时弹出系统的提示框和系统设置，两个说的是同一件事。
- 指针停在纸上时的 ⌫、空格、⌘Z、⌘C、Esc 按 [T-002](T-002-only-option-c-global.md) 去掉了，对应的功能要等第 ③ 步的按键表。菜单栏里的「在晾衣绳上搜索」并进了「显示晾衣绳」。
- 本机构建是 ad-hoc 签名，每重新构建一次，辅助功能的授权就失效，见 [T-016](T-016-stable-signing.md)。
- design-integrity-review：PASS，没有确认的问题；它指出的换屏情形就是 T-015。
