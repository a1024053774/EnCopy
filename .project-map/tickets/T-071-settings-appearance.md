## What to build

用户 2026-11-25 说设置面板不直观，主题藏得太深找不到（它是「晾衣绳」页第二块里的一个下拉框）。当天定下：

- 设置第二页加「外观」：通用 / 外观 / 挂上复制的内容 / 截图 / 晾衣绳 / 保留。页名其余不改。
- 外观页最上面是主题：六张小图卡，每张是那个主题下一小段绳子挂两张纸、底下写名字，当前的描边；点了就换，设置窗口跟着换。下面是大小（小 / 中 / 大三段）、显示来源 App、悬停时放大，从晾衣绳页搬过来。
- 晾衣绳页只剩什么时候放下来、绳上保留几件。
- 保留页先给能调的：原图上限、用了多少、清理按钮在最上；保留规则其次；「EnCopy 怎么存东西」只露「都在这台 Mac 上」一行，长说明默认收起，点「展开说明」才出来。
