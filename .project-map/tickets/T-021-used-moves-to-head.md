## What to build

[T-019](T-019-paste-moves-to-head.md) 定了：绳上的一件被用到，就回到绳头，和篮子里的一样。用到指 ⌥C 后 ⏎ 贴出去、在绳上点一下复制、菜单里「复制」。几件一起复制的，按它们在绳上的先后一起回到绳头。收藏的和拿在手上的留在原位。退出重开后顺序还在。

## Acceptance

- [ ] ⌥C 后挑一件不是最新的，⏎ 贴出去；再按 ⌥C，选中的第一件就是刚贴的那件，和剪贴板里的一样。
- [ ] 在绳上点一下复制一件，它回到绳头；其余几件的先后不变。
- [ ] 几件一起复制，它们按原来的先后一起回到绳头。
- [ ] 收藏的、拿在手上的被复制后留在原位。
- [ ] 退出重开后，绳上的顺序是挪过之后的顺序。
- [ ] 自动检查通过。原有检查里有两项假定「复制不改顺序」，按 T-019 改预期，其余不改。
- [ ] 真机：在备忘录里 ⌥C 挑第三件 ⏎ 贴出，再 ⌥C，选中的是它；点一下复制另一件，它回到绳头。留截图和步骤。
