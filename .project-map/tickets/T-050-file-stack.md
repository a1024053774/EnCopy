## What to build

[T-048](T-048-files-retention-settings.md) 的第二刀：在访达里一次复制两个以上的文件，绳上只挂一张「N 个文件」的文件夹纸，写着头几个文件名；不再卡 20 个。⏎ 贴出时把 N 个路径一起放回剪贴板，和在访达里复制一样；它回到绳头。它进历史和篮子，篮子列表里是一行「N 个文件」，按其中任何一个文件名都搜得到；这一行能展开，看每个文件名，选其中一个单独贴。同样的一批文件再复制一遍，不多出一件，原来那张回到绳头。
