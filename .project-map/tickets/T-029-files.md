## What to build

在访达里复制的文件（和文件夹）挂上绳：只记路径，不复制文件本体；纸是牛皮纸文件夹，写文件名和所在的文件夹。从绳上复制回去，剪贴板里是这个文件。搜索按文件名和所在文件夹找；Tab 多一档「文件」。取下只从绳上拿下来，文件不动。菜单「挂上复制的内容」多一个「文件」开关，默认开。

- [x] 按文件名和所在文件夹都搜得到；Tab 的「文件」一档只显示文件。

- [x] 自动检查通过。T-025 的 Tab 检查按新的一档改了预期（那张单写明文件挂上绳后加这一档），其余不改。
