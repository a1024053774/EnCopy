## What to build

用户问：复制的文件会不会多存一份、占不占地方？App 里没有地方说明。在设置的「保留」页加一节「EnCopy 怎么存」，每一类东西写一行，照代码现在的做法写，不多承诺：

- 文字、链接和代码：存成一个小文件，放在数据文件夹里；同样的内容再复制一遍不多存一份。
- 截图和从 App 里复制的图片：原图存在数据文件夹里，30 天后或超过上限时缩成缩略图。
- 录屏：存在数据文件夹里，掉下绳时进废纸篓。
- 访达里复制的文件：不复制、不建替身，只在一张清单里记下路径；文件留在原处，EnCopy 不移动也不改它；清掉时只删这张清单。
- 访达里的图片和视频：直接显示原文件，不复制；离开绳子后原文件不动。
- 最后一行：这些都只在这台 Mac 上，EnCopy 不联网；旁边一个按钮在访达里打开数据文件夹。

产品页和 README 跟着写上同样的意思。

## Acceptance

- [ ] 「保留」页有「EnCopy 怎么存」一节，上面几类各一行，中英文都有；按钮在访达里打开的是当前这份 App 的数据文件夹（开发版打开开发版的）。
- [ ] 每一行说的和代码现在的做法对得上：访达的文件不会出现在数据文件夹里，只有路径清单；录屏掉下绳进废纸篓；访达的图片不复制。
- [ ] 自动检查覆盖：访达里复制文件后，数据文件夹里没有这个文件的副本，只多一张清单；按钮用的文件夹是数据文件夹。
- [ ] 真机：六套主题下截「保留」页，看得清；点按钮打开的是开发版的数据文件夹。
