## What to build

用户 2026-11-25 要一套圣诞季主题，当天定下：

- 一直能选，不看日期；外观页它的卡上斜挂一条像礼物丝带的「季节限定」角标，提醒用户有它。
- 样子：冬青绳（深绿绳上一段段浅绿叶子）挂一串小彩灯，夹子是红白拐杖糖（收藏的是绿白），纸是奶油色贺卡，里面一圈红线一圈绿线；选中描边是圣诞红。设置窗口底色是深绿。
- 彩灯轮流慢慢亮暗；开着「减弱动态效果」时全亮、不动。
- README 和产品页「六套主题」改成七套，配一张圣诞主题的真实截图。

## Resolution

2026-11-26。`Theme` 加 `.christmas` 和 `isSeasonal`；绳子是冬青绳加 `FairyLights`（每 0.8 秒三盏里暗一盏，轮着来；减弱动态效果时全亮不动），夹子是 `CandyCane`，纸是贺卡（一圈红线一圈绿线）；外观页卡上挂 `SeasonRibbon`。README、README.en、产品页改成七套主题，加了中英文两张圣诞主题图（`docs/themes/christmas.png`、`docs/themes/en/christmas.png`，开发版在内建 Retina 屏上放下绳子、按窗口号截的）。

- 本地检查：`ENCOPY_CHECKS_SCREEN="EnCopy walk screen" scripts/check.sh`，474 checks passed（七套、各有名字、只有圣诞季是季节限定、任何一天都能选）。
- 开发版第一轮发现三处并改掉：丝带上的字被裁一半（往里挪）；设置的页签和大块也套上了贺卡边和冬青，压住文字和勾选框（`ThemeCardBackground` 加 `decorated`，设置和篮子列表的行关掉）；卡角的冬青压住来源 App 图标或文字（四个角都有东西，冬青去掉）。截图 `evidence/T-072/01`–`07`。
- 改后：外观页七张卡，圣诞季的丝带「季节限定」完整，点它设置窗口变深绿（`05-外观-圣诞季-改后.png`）；绳子是冬青绳、彩灯、拐杖糖、贺卡纸（`08-绳子-a.png`）；隔 0.9 秒两张图里红灯、黄灯亮暗互换（`c-08`、`c-09`）；用户同意后临时开减弱动态效果，两张图彩灯全亮一样（`c-10`、`c-11`），随后关回去，系统读回 false。
- 没验：收藏的绿白拐杖糖（这次没收藏件）；篮子列表里圣诞主题的行。
