## Question

哪些按键是全局快捷键？

## Resolution

只注册 ⌥C 一个全局快捷键，可以改。其余按键只在 ⌥C 把绳子拉下来、面板拿到键盘之后才有效；绳子一收，这些键全部还给前台 App。路过模式只用鼠标，不拿任何键。Tendedero 现有的 ⌃⌥T、⌃⌥F，以及指针停在绳上时临时注册的 ⌫、空格、⌘Z、⌘C、Esc 全部去掉。

来源：用户 2026-11-22「这些快捷键只有 option 我要全局的，其他都是做成打开绳子后再生效的」。完整按键表见[设计方案 v0.3「按键」](../../design/encopy-design.html#keys-sec)。
