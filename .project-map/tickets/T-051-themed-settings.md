## What to build

[T-048](T-048-files-retention-settings.md) 的第三刀：设置窗口加一页「保留」，写着文字留多久、原图几天后缩成缩略图、原图上限（能选），以及现在原图一共占了多少、下次保留规则会清掉和缩小几件。「清理历史…」面板里的「保留」一节去掉，面板只留手动清理和「最近清掉」。整个设置窗口换成 EnCopy 自己的样子：每一节是一张纸，颜色、边、字体用当前主题的，在设置里换主题时窗口跟着变；开关、选项照旧好用，键盘和「减弱动态效果」照旧可用。

## Acceptance

- [x] 设置里有「保留」一页，原图上限改了之后保留规则用新值；页上的占用和「下次会清几件」和清理面板原来算的一致。清理面板里不再有「保留」一节。
- [x] 设置窗口的每一节是纸的样子，换主题后窗口里的纸、边、字体跟着变；六套主题下都能看清、能操作。
- [x] 自动检查覆盖：上限设置被保留规则读到；「下次会清几件」和保留规则的计划一致。
- [x] 真机：六套主题下各截一张设置窗口，看得清，开关能用。

## Resolution

完成，2026-11-23。设置窗口换成五个纸标签：通用、挂上复制的内容、截图、晾衣绳、保留。每一节是一张当前主题的纸，背景、边、字体、勾选颜色跟着主题，在「晾衣绳」页换主题时窗口当场跟着变。「保留」页写文字、截图和图片、访达里的文件、绳上的和收藏的各留多久；原图上限能选 512 MB / 1 GB / 2 GB / 5 GB，下面是原图已用和上限、下次会过期和缩小几件，以及「清理历史…」按钮。清理面板里的「保留」一节去掉了，种类里加了「文件」。提交 `22a2bb8`，词汇表和 README `717d28a`。

检查：`checkRetentionStatus` 3 项（页上「会过期几件、缩小几张」和保留规则的计划一致；占用和 1 GB 上限对得上；在那里设小一点的上限后，保留规则就用它，较旧的原图会缩小）。把上限改成不从设置里读时报错。`scripts/check.sh`：455 项通过。

真机（2026-11-23 23:08–23:12，开发版，外接屏；证据在本地 `evidence/T-051/`）。打开设置，在「晾衣绳」页的主题菜单里依次选六套主题，每套截「晾衣绳」页和「保留」页。

- 第一轮发现两处：像素主题下每个字后面都跟着一个错开的影子，读不清（阴影加在整张纸上，落到了每个字后面）；「保留」页选的是 1 GB，下面却写「上限 1.07 GB」（上限按 1024 算，显示按 1000 算）。改成阴影只落在纸上、大小按 1024 显示，顺带去掉标签按钮的蓝色焦点框，提交 `3805623`。
- 修好后六套主题都看得清，主题菜单当场换掉窗口的样子，上限写「1 GB」（`settings-line-sheet.png`、`settings-keep-sheet.png`，单张是 `1-line-纸.png` 到 `6-keep-手账.png`）。
