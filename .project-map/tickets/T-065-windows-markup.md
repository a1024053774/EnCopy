## What to build

Windows 系统截图工具不提供可供第三方写回覆盖的编辑扩展回调，因此内置一个简洁好用的图片标注窗，实现 Mac 版长按卡片或右键「标记」写回原图的完整闭环。依据 [T-056](T-056-windows-platform-and-release.md)。

包含内容：

- **写回权限边界**：仅对 EnCopy 自己文件夹（`EnCopy\Screenshots\`）内或桌面截图放开「标记」写回；来自资源管理器的普通图片和 PDF 一律只打开快速查看，不改写用户外部原文件。
- **触发方式**：卡片长按（约 0.45 秒有按压反馈）、卡片右键「标记」、或「拿在手上」浮窗右键「标记」。
- **内置标注能力**：画笔、矩形/圆框、箭头、半透明荧光笔、马赛克打码、文字标注、裁剪、颜色与粗细切换，以及多步撤销/重做（`Ctrl+Z`/`Ctrl+Y`）。
- 点「完成 / 保存」时按原文件格式（PNG/JPEG/WebP 等）原子覆盖写回原文件（若取消或点右上角关闭则不改原图），随后立即刷新绳上缩略图、记录大小变化并重跑一次 `Windows.Media.Ocr` 更新图片文字索引。

## Acceptance

- [ ] 长按约 0.45s 或右键「标记」可打开标注窗（仅针对 EnCopy 自己目录内的图片及桌面截图；外部图片与 PDF 自动退回快速查看）。
- [ ] 支持画笔、矩形框、箭头、荧光笔、马赛克、文字、裁剪与撤销/重做，能实际修改像素并保存。
- [ ] 保存按原图片格式原子覆盖写回原路径，绳上卡片缩略图即时更新，图中新增/抹除的文字重新触发 OCR 刷新索引；取消关闭不改动原文件。
- [ ] `windows/scripts/check.ps1` 覆盖可编辑目标边界判定、各标注图元无损渲染合图、原格式写回及索引重刷新并全绿。
- [ ] 真机走查：使用 `EnCopy Dev` 对一张截图长按进入标记，画箭头、打马赛克并加字保存后，验证贴出的图片含标注且可按新加的文字搜到，留前后对比截图在 `evidence/T-065/`。
